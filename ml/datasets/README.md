# Datasets

Coloque aqui apenas manifestos e amostras publicas autorizadas. Datasets clinicos brutos, imagens de pacientes e mascaras grandes nao devem ser versionados.

Antes de usar qualquer fonte:

- confirme licenca e termos;
- registre origem e versao;
- remova metadados identificaveis;
- documente consentimento/base legal quando for dado interno Heal+.
