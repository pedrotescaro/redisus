# Demo Script

## Objetivo

Demonstrar o valor do módulo de diagnóstico em menos de 7 minutos, sem depender de explicações longas ou promessas futuras.

## Roteiro

### 1. Abertura

- apresentar o problema: avaliação de feridas ainda é heterogênea e pouco rastreável;
- posicionar o HEAL+ / REDISUS como apoio à documentação e análise por imagem.

### 2. Contexto do caso

- abrir um paciente;
- mostrar o histórico resumido;
- criar uma nova avaliação.

### 3. Entrada de dados

- anexar imagem;
- preencher dados clínicos mínimos;
- mostrar que o fluxo está ligado ao caso correto.

### 4. Análise

- disparar a análise;
- mostrar o retorno principal;
- explicar composição tecidual, etiologia sugerida e confiança;
- deixar claro quando o resultado é experimental e requer revisão profissional.

### 5. Relatório

- gerar ou abrir o relatório;
- mostrar persistência no histórico;
- demonstrar comparação entre avaliações se disponível.

### 6. Fechamento

- reforçar diferenciais atuais: organização técnica, rastreabilidade, benchmark em consolidação e prontidão para evolução;
- não prometer produção clínica final antes da validação adequada.

## Assets que faltam

- screenshots oficiais em `docs/media/screenshots/`;
- GIF curto do fluxo;
- um caso sintético consistente para apresentação.
