# Data Classification

## Sensível crítico

- imagens de feridas
- dados clínicos de paciente
- relatórios estruturados
- histórico de atendimento e evolução

## Sensível operacional

- service accounts
- tokens de IA
- credenciais de storage e banco

## Regras

- dado clínico não entra em screenshot pública
- dado real não entra em dataset de demo
- URLs públicas para imagem clínica são proibidas
- logs não devem conter payload clínico bruto
- relatórios e exports devem ter retenção definida e descarte seguro
