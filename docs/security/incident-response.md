# Incident Response

## Quando acionar

- suspeita de acesso indevido a paciente
- vazamento de secret ou service account
- upload malicioso com impacto operacional
- envio indevido de contexto clínico para terceiro

## Passos imediatos

1. conter o acesso e revogar credenciais
2. preservar evidências e logs
3. identificar recursos e pacientes afetados
4. corrigir a causa raiz
5. documentar linha do tempo e decisão

## Pós-incidente

- rotacionar segredos
- revisar regras de acesso
- adicionar teste de regressão
- atualizar documentação e controles
